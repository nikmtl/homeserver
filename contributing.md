# Contributing

Contributions to this project are welcome! If you have experience with self-hosting, Cloudflare Tunnel, Dokploy, or any of the services mentioned in the documentation, please feel free to share your insights by [creating an issue](https://github.com/nikmtl/homeserver/issues/new/choose).

> [!NOTE]
> If you have a security concern, please see the [security policy](./security.md) for details on how to report it responsibly.
