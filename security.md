# Security Policy

## Reporting a Vulnerability in the Server Setup

If you discover a security vulnerability in the setup of the server, please report it responsibly by contacting me directly at [contact@mtzel.com](mailto:contact@mtzel.com). Do not publicly disclose the vulnerability until it has been addressed.

For more details on the security measures in place, see the [security documentation](./docs/security.md).

Thank you for helping to keep the server secure!
